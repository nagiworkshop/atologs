# Changelog

## [v1.0.0] - 2026-05-31

First public release of AtoLogs — a usage leaderboard for coding agents (Claude Code / Codex) among friends.

### Features
- Rank token usage and cost across group members, with daily / weekly / monthly / all-time views and activity charts.
- Privacy-first sharing: private by default; opt in to the global leaderboard with `atologs profile --public` (or `--private`), or via the dashboard toggle.
- Simple setup: `npx atologs init`.
